## The rant

The self-checkout accused me of stealing my own milk — scanned it, watched
me scan it, then screamed "UNEXPECTED ITEM IN THE BAGGING AREA" like I'd
smuggled contraband dairy past a border. All while I stood there holding the
receipt for a crime committed on camera, waiting for a teenager in a vest to
stroll over, press one button, and pardon me.

## How it works

Run the entry program:

```sh
python3 main.py
```

It writes the rant (344 characters, inside the 1–400 character gate) to
`/output/entry.txt`. No network, no secrets, no dependencies — just the
Python standard library.
